# 座標・姿勢融合・重力補償

## 座標の定義

| 座標系 | 正方向 |
| --- | --- |
| デバイスD | X＝右、Y＝上、Z＝装着者側。視線前方は−Z |
| OS Quaternionの世界W | Androidの世界座標。重力に対応する静止加速度は+Z方向 |
| 自前融合の世界W | 起動時の任意Yawをもつ右手系。静止加速度は+Y方向 |
| RESET基準R | 校正完了時のデバイスDと同じ向き。その後は固定 |

世界WはOS入力と自前融合で異なるため、入力方式を切り替えた場合は必ず再校正します。すべてQuaternionはHamilton方式、成分順は(w,x,y,z)。`q` はD→Wの能動回転です。Android Rotation Vector入力の並び(x,y,z,w)は入力部で変換します。

## Gメーター

`aD`＝SensorManager加速度、`bD`＝校正したデバイス軸のバイアス、`q0`＝RESET時のD→W姿勢、`gW`＝静止時に重力によって観測される加速度ベクトル。

```text
aW = rotate(q, aD - bD) - gW
aR = rotate(inverse(q0), aW)
LAT_G  = +aR.x / 9.80665
LONG_G = -aR.z / 9.80665
```

バイアスはデバイスに固定されているため回転前に除去します。世界座標やRESET座標の一定オフセットとして引くと、頭を傾けた際に誤差になるためです。

LPFは実際のサンプル間隔dtを使う1次指数フィルタです。

```text
alpha = 1 - exp(-2*pi*G_FILTER_CUTOFF_HZ*dt)
y = y + alpha*(x-y)
PEAK = max(PEAK, sqrt(filtered_LAT² + filtered_LONG²))
```

標準fc=4Hzでは時定数約39.8ms、90%到達約91.6msです。描画や姿勢までこのLPFを通しません。長いサンプル欠落後は古いLPF状態を引きずらず再初期化します。Gメーターは円周外へ出ないようドット位置を制限しますが、計測数値を±2Gに切り詰めません。

PEAKはフィルタ後の平面加速度のピークです。生の3軸合成G、重力込みのG、各軸別のピークではありません。

## Pitch / RollとYawの独立性

姿勢から現在のデバイス座標での世界上方向 `uD = inverse(q) * worldUp` を求めます。

```text
pitchAbs = atan2(-uD.z, sqrt(uD.x² + uD.y²))
rollAbs  = atan2(-uD.x, uD.y)
pitchHUD = pitchAbs - pitchAbs_at_reset
rollHUD  = wrap180(rollAbs - rollAbs_at_reset)
```

これにより、上を向くとPitch正、右に傾けるとRoll正。重力まわりのYawが変わってもPitch/Rollは変わりません。傾いた状態でRESETしても同じ性質を保ちます。**完全な相対Euler角を表示する実装ではなく、重力基準の傾斜角にゼロ点オフセットを適用**しています。G演算には省略しないQuaternion変換を使用します。

画面の機体マーカーは固定。水平線の座標系を `-rollHUD` 回転し、姿勢座標内で `pitchHUD × 3.1px/deg` 下へずらします。正のPitchでは水平線が下がり、右Rollでは水平線右端が上がります。遠近投影による厳密な視野角校正ではなく、角度目盛のHUDです。

## センサーフュージョン

1. 起動時にOSのGAME_ROTATION_VECTORを探し、無ければROTATION_VECTORを探します。GAMEを優先するのはPitch/Rollに地磁気方位を必要としないためです。
2. 登録失敗・未搭載ならジャイロ＋加速度へ。OS姿勢が150ms以上停止、またはUNRELIABLEが2秒以上続いた場合も自前融合へ切り替えます。起動直後は2秒の猶予を置きます。
3. 自前融合はMahony方式の比例重力補正です。ジャイロから固定残留バイアスを引き、予測上方向と正規化加速度の外積を角速度へ加えます。Quaternionの更新は回転指数写像を使い、毎回正規化します。
4. 加速度の大きさが1Gから6%以上外れる場合、または重力方向とのずれが2.5°以上の場合は重力補正を止めます。大きな並進加速度を傾きへ誤変換しにくくするためです。
5. 積分型のバイアス適応は走行中の誤学習を避けるため使いません。gyro biasは静止校正で取得します。Yaw補正はありません。

ゲートは完全な静止／加速分類器ではありません。小さい持続加速度、温度ドリフト、ジャイロオフセット変化は残ります。重力方向との誤差がゲートを超えた場合は重力補正だけで復帰しないこともあるため、静止してRESETしてください。

## 時刻・スレッド

- センサー計算のdtはセンサー時刻の差。コールバック到着時刻や描画フレーム間隔から積分しません。
- 描画は `elapsedRealtimeNanos` とセンサー時刻を比較し、150msより古い値をライブ表示しません。
- G計算に使用する最新姿勢と加速度の時刻差は最大30ms。Quaternionの未来予測や加速度の二重積分はありません。
- 単一のIMUスレッドがEngineを書き込み、短い同期区間でprimitiveだけをSnapshotへコピーします。描画側は独自のコピーを使います。
- `Vec3`、Quaternion、数値文字バッファ、Paint、軌跡配列を再利用します。OS内部のCanvasやSensorEvent実装まで無割り当てを保証するものではありません。
- 任意CSVは別のI/Oスレッドで10Hz。IMU全サンプルの無損失レコーダーではありません。

## 軸の変更

`AxisMap(x,y,z)` の各引数は元センサー軸を指定する±1..±3です。例えば(2,-1,3)は新X=旧Y、新Y=−旧X、新Z=旧Z。行列式+1の回転のみを受け付け、鏡映を拒否します。Quaternionも同じ座標変換へ対応させます。実機検証なしに符号を反転することは避けてください。
