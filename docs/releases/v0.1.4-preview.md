## 日本語

OS姿勢だけの変化で生IMUの集計窓を消去しないように変更。不安定なOS姿勢は棄却し、本体の加速度・ジャイロによる融合へ切り替えます。

この修正版の実機試験は未実施。大きな動きが続く場合に校正を終了させる時間上限はまだありません。

- 検証：模擬IMU 39項目、APK内部11項目。実機の軸符号・ボタン・60fpsは未確定です。
- インストール：`adb install -r RokidHUD-0.1.4-debug.apk`。本体のみで動作し、実行中のスマホ・Bluetooth・ネット接続は不要です。
- 計測対象はメガネ本体です。頭部運動がG値に混入します。

## English

Keeps the raw-IMU statistics window when only OS attitude changes. Rejects unstable OS attitude and switches to accelerometer/gyroscope fusion on the glasses.

This revision has not been tested on physical hardware. There is still no calibration deadline when larger movements persist.

- Verification: 39 synthetic IMU checks and 11 static APK checks. Physical axis signs, button delivery and 60fps remain unverified.
- Install: `adb install -r RokidHUD-0.1.4-debug.apk`. Runtime is standalone: no phone, Bluetooth link or server.
- Acceleration is measured at the glasses and includes head movement.
