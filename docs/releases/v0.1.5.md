## 日本語

通常は約1秒で校正。10秒で静止判定を緩和し、15秒でも未完了なら新鮮で妥当なIMU入力から暫定基準でHUDを開始します。緩和・暫定開始はAPPROXと表示。欠測や不正入力ではIMU DATA ERRORを表示し、無期限に校正を続けません。

この版の実機・エミュレーター試験は未実施。GitHub上の正式リリース区分は実機検証や精度認証を意味しません。暫定校正では誤差が増えるため、静止してRESETすると通常校正をやり直せます。

- 検証：模擬IMU 47項目、APK内部11項目。実機の軸符号・ボタン・60fpsは未確定です。
- インストール：`adb install -r RokidHUD-0.1.5-debug.apk`。本体のみで動作し、実行中のスマホ・Bluetooth・ネット接続は不要です。
- 計測対象はメガネ本体です。頭部運動がG値に混入します。

## English

Normally calibrates in about one second. Relaxes stillness criteria after 10 seconds and starts with a provisional reference after 15 seconds if fresh, plausible IMU input is available. Relaxed/provisional results display APPROX. Missing or invalid input produces IMU DATA ERROR instead of waiting indefinitely.

This version has not been run on physical hardware or an emulator. Its GitHub release status does not imply hardware validation or certified accuracy. Provisional calibration can increase error; keep still and reset to retry normal calibration.

- Verification: 47 synthetic IMU checks and 11 static APK checks. Physical axis signs, button delivery and 60fps remain unverified.
- Install: `adb install -r RokidHUD-0.1.5-debug.apk`. Runtime is standalone: no phone, Bluetooth link or server.
- Acceleration is measured at the glasses and includes head movement.

正式公開APKはversionName **0.1.5** / versionCode **7**。先行previewと同じ署名で更新できます。姿勢・G演算とHUD描画は先行previewと同一。Android 12向け登録処理のlint対応を追加しました。

The published APK uses versionName **0.1.5** / versionCode **7**, signed with the original key for in-place upgrades. Fusion and HUD behavior are unchanged; the Android 12 receiver-registration branch now has a scoped lint annotation.
