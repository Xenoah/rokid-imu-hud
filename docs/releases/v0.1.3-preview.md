## 日本語

OS姿勢の変化も静止判定に使用し、OS姿勢から求めた回転分を差し引いてジャイロバイアスを推定します。

その後のユーザー動画では約247Hzで入力を受信していましたが、OS姿勢の変化による校正のやり直しが残っていました。

- 検証：模擬IMU 32項目、APK内部11項目。実機の軸符号・ボタン・60fpsは未確定です。
- インストール：`adb install -r RokidHUD-0.1.3-debug.apk`。本体のみで動作し、実行中のスマホ・Bluetooth・ネット接続は不要です。
- 計測対象はメガネ本体です。頭部運動がG値に混入します。

## English

Uses OS attitude changes alongside angular velocity for calibration, subtracting estimated real rotation when estimating gyro bias.

Subsequent user video showed approximately 247Hz input, but OS attitude changes still caused repeated calibration restarts.

- Verification: 32 synthetic IMU checks and 11 static APK checks. Physical axis signs, button delivery and 60fps remain unverified.
- Install: `adb install -r RokidHUD-0.1.3-debug.apk`. Runtime is standalone: no phone, Bluetooth link or server.
- Acceleration is measured at the glasses and includes head movement.
