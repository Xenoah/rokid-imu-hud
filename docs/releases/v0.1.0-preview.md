## 日本語

水平線、Pitch ladder、Roll目盛、固定機体マーカー、±2Gメーター、Peak Hold、3表示モードを実装。OS Quaternionを優先し、自前Mahony融合へフォールバックします。

履歴保存用。Android 12の画面初期化順序による起動失敗の可能性と、校正待機が長引く問題が後続版で判明しています。

- 検証：模擬IMU 16項目、APK内部11項目。実機の軸符号・ボタン・60fpsは未確定です。
- インストール：`adb install -r RokidHUD-0.1.0-debug.apk`。本体のみで動作し、実行中のスマホ・Bluetooth・ネット接続は不要です。
- 計測対象はメガネ本体です。頭部運動がG値に混入します。

## English

Introduces the artificial horizon, pitch ladder, roll scale, fixed aircraft marker, ±2G meter, peak hold and three display modes. Prefers the OS quaternion, with Mahony fusion as a fallback.

Historical preview. Later investigation identified a possible Android 12 startup failure and indefinitely repeated calibration.

- Verification: 16 synthetic IMU checks and 11 static APK checks. Physical axis signs, button delivery and 60fps remain unverified.
- Install: `adb install -r RokidHUD-0.1.0-debug.apk`. Runtime is standalone: no phone, Bluetooth link or server.
- Acceleration is measured at the glasses and includes head movement.
