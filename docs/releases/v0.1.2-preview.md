## 日本語

時間窓の統計による静止判定、低頻度のOS姿勢への対応、重力と整合しない姿勢の棄却を追加。待機理由、ACC、GYRO、取得Hzを表示します。

スマートフォンでHUD描画、グラスで起動・描画・約198HzのIMU受信がユーザー画像で確認されました。ただしグラスでは校正待機が続いていました。

- 検証：模擬IMU 24項目、APK内部11項目。実機の軸符号・ボタン・60fpsは未確定です。
- インストール：`adb install -r RokidHUD-0.1.2-debug.apk`。本体のみで動作し、実行中のスマホ・Bluetooth・ネット接続は不要です。
- 計測対象はメガネ本体です。頭部運動がG値に混入します。

## English

Uses windowed statistics for stillness detection, tolerates slower OS attitude updates, and rejects attitude inconsistent with gravity. Displays the wait reason, accelerometer, gyroscope and measured sample rates.

User images show the HUD on a phone and startup, rendering and approximately 198Hz IMU input on the glasses. Calibration was still stuck on the glasses.

- Verification: 24 synthetic IMU checks and 11 static APK checks. Physical axis signs, button delivery and 60fps remain unverified.
- Install: `adb install -r RokidHUD-0.1.2-debug.apk`. Runtime is standalone: no phone, Bluetooth link or server.
- Acceleration is measured at the glasses and includes head movement.
