## 日本語

DecorView生成前のInsetsController参照を避け、View生成後にシステムバーを設定するよう修正。起動失敗時のログ採取も改善しました。

履歴保存用。校正待機が繰り返される問題はこの版では未解決です。

- 検証：模擬IMU 16項目、APK内部11項目。実機の軸符号・ボタン・60fpsは未確定です。
- インストール：`adb install -r RokidHUD-0.1.1-debug.apk`。本体のみで動作し、実行中のスマホ・Bluetooth・ネット接続は不要です。
- 計測対象はメガネ本体です。頭部運動がG値に混入します。

## English

Moves system-bar configuration after view creation, avoiding early InsetsController access. Improves log capture when startup fails.

Historical preview. Repeated calibration waiting is not resolved in this version.

- Verification: 16 synthetic IMU checks and 11 static APK checks. Physical axis signs, button delivery and 60fps remain unverified.
- Install: `adb install -r RokidHUD-0.1.1-debug.apk`. Runtime is standalone: no phone, Bluetooth link or server.
- Acceleration is measured at the glasses and includes head movement.
