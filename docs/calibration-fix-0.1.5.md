# 0.1.5：校正待ちに時間上限を設定

更新日：2026-09-19 UTC。`RokidHUD-0.1.5-debug.apk`、正式公開APKはversionCode 7（先行previewは6）。配布済み0.1.0〜0.1.4と同じ署名で上書きできます。

「10秒以上続いたら判定を緩め、校正が終わらない状態をやめたい」という要望に合わせ、校正の終了条件を変更しました。

| 経過時間 | 動作 | 校正品質 |
| --- | --- | --- |
| 0〜10秒 | 従来の約1秒の静止窓で校正 | 合格時 `STANDARD` |
| 10秒以降 | 観測窓を0.5秒に短縮し、振動・角速度分散・傾斜変化の判定を緩和 | 合格時 `RELAXED`、HUDに `APPROX` |
| 15秒 | 未完了でも、新鮮で妥当な範囲の加速度・ジャイロがあれば暫定基準でHUDを開始 | `PROVISIONAL`、HUDに `APPROX` |
| センサー欠落／不正入力 | `IMU DATA ERROR` で終了。正常値を捏造して開始しない | 有効な計測値なし |

通常の静止入力は約1秒で従来どおり開始します。OS姿勢の棄却を伴えば約2秒です。15秒の処理は加速度イベントまたは500msごとの監視で実行されるため、イベント停止時には最大約0.5秒の検出間隔が加わります。スレッド停止・OS停止まで含めた厳密な実時間保証ではありません。

## 緩める条件

| パラメーター | 通常 | 10秒以降 |
| --- | --- | --- |
| 連続観測窓 | 1秒 | 0.5秒 |
| 加速度の標準偏差目安 | 1軸0.12m/s² | 1軸0.35m/s² |
| ジャイロの標準偏差目安 | 自前0.035／OS 0.075rad/s | 0.12rad/s |
| 生加速度方向の最大変化 | 2° | 6° |
| 加速度ノルムの1Gからの許容差 | 0.6m/s² | 1.0m/s² |
| ジャイロ単発値の上限 | 0.35rad/s | 0.60rad/s |

分散の実判定は各目安の二乗×3と3軸分散合計の比較です。最小サンプル数20、バイアスの上限、入力の鮮度は緩めません。信頼性を疑うOS姿勢の2°判定も維持し、その場合は自前融合へ切り替えます。切替・窓の取り直し・校正中の入力間隔異常によって、元の10秒／15秒タイマーを延ばしません。利用者がRESETした場合は新しい校正要求です。

## 15秒での暫定開始

静止を確認できていないため、この経路では新しいジャイロ／加速度バイアスを推定しません。既に確定した補正値があれば保持し、初回起動ならアプリによる追加補正はゼロを使用します。Androidが提供するセンサー値への補正を解除する意味ではありません。

最新の補正済み加速度方向から初期姿勢を作り、自前融合に切り替え、Pitch/Rollのゼロ点とG基準、Peak、フィルタを初期化します。入力の鮮度は150ms以内、加速度ノルムは0.5〜1.5G、ジャイロノルムは20rad/s以下という妥当性の検査を残します。これは精密な静止校正ではなく、表示を開始するための暫定基準です。加速中の見かけの重力や未補正バイアスにより、傾きやGの誤差・ドリフトが増える場合があります。

`APPROX` はRELAXEDまたはPROVISIONALである限り表示します。静止して2本指ダブルタップでRESETし、通常条件の校正に成功すると消えます。暫定値のまま何も告げず通常精度へ扱いを変更する処理はありません。

6軸IMUでは一定Yawと一定ジャイロオフセット、持続並進加速度と重力を完全に分離できない制約は残ります。計測対象は頭部に装着したメガネの加速度です。

## 表示・ログ

- 校正画面：経過秒と `15S MAX`。10秒以降は `EASY CALIBRATION`。
- HUD：画面上部に `APPROX`。単色緑、中央の視認性を維持。
- 不正入力：`IMU DATA ERROR` と不足している入力の理由。入力を確認してRESETで再試行。
- Logcat：校正品質が変わった時の品質・経過秒。
- 任意CSV：`cal_elapsed_s`、`cal_relaxed`、`cal_quality` を追加（全38列）。

`tools/debug-device.py` の収集時間は20秒へ変更しました。15秒の暫定開始を観測できるようにし、結果JSONへ `calibration_quality` を追加しています。`RUNTIME_SMOKE_PASS` は起動・プロセス生存・有効データの確認であり、精密校正の合格を意味しません。

## 検証

47項目の模擬試験に合格しました。新規8ケースは、通常約1秒の開始、198/247Hzで10秒後の緩和、15秒の暫定開始、姿勢源変更をまたぐ期限、欠測・NaN・不正スケールのエラー終了、RESETでの通常校正復帰、既存バイアス保持、監視による期限処理です。

以前の4件の運動・振動拒否試験は、通常判定の0〜10秒を対象とする試験に変更しました。15秒を過ぎても拒否し続ける旧仕様は、今回の依頼に合わせて廃止しています。

Androidコンパイル・DEX生成・署名・整列・APK内部11項目、CSV38列の本番書式、診断スクリプトの疑似ADB3経路を検証済みです。描画は本番レンダラーのJava2Dプレビューで確認しました。**0.1.5のRokid実機／エミュレーター実行は未確認です。**
